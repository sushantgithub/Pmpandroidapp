# PMP Study

Original Android study companion for the PMP exam content outline: People, Process, and Business Environment, plus predictive/agile delivery notes, earned-value formulas, and a short practice quiz.

This project is **not affiliated with, endorsed by, or derived from PMI courseware** or any commercial note set. It is independent study commentary.

## Build

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleDebug testDebugUnitTest
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

## Install

Enable unknown sources, then install the APK on a device running Android 8.0 or later.
